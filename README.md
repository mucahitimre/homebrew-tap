# mucahitimre/tap

Homebrew tap for [Shutterbar](https://github.com/mucahitimre/Shutterbar) (formerly MacShot) — ShareX-style screenshots for macOS.

```bash
brew install --cask mucahitimre/tap/shutterbar
```

Update with `brew upgrade --cask shutterbar`. Uninstall with `brew uninstall --cask shutterbar` (add `--zap` to also remove preferences).

> The old `macshot` cask was removed: that token belongs to a different app in Homebrew's main repository. If you installed MacShot from this tap, run `brew uninstall --cask mucahitimre/tap/macshot` and install `shutterbar`.
