# mucahitimre/tap

Homebrew tap for [MacShot](https://github.com/mucahitimre/MacShot) — ShareX-style screenshots for macOS.

```bash
brew install --cask mucahitimre/tap/macshot
```

Update with `brew upgrade --cask macshot`. Uninstall with `brew uninstall --cask macshot` (add `--zap` to also remove preferences).
